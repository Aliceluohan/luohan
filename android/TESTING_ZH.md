# Money Manager 安卓测试说明

## 上传到 GitHub

1. 将整个 `android` 文件夹上传并覆盖到原来的 GitHub 仓库。
2. 如果仓库里还没有 `.github/workflows/build-apk.yml`，也要上传项目根目录的 `.github` 文件夹。
3. 打开仓库的 **Actions** 页面，等待 **Build Android APK** 变成绿色。
4. 打开仓库的 **Releases**，进入“最新安装包”，下载 `moneymanager-debug.apk`。

如果手机提示签名不一致，请先卸载旧版再安装。本轮没有需要保留的数据，可以安全卸载；正式使用前会再配置固定签名。

## 红米 Turbo 4 首次设置

打开 Money Manager → 右上角设置：

1. 开启“通知监听权限”，在系统列表中允许 Money Manager。
2. 开启“小结系统通知”，允许 App 发送通知。
3. 阅读“增强自动记账”说明后，自愿开启辅助功能。
4. 在红米的“后台自启动”中允许 Money Manager。
5. 在耗电管理中将 Money Manager 设为“不限制”。

增强自动记账只检查微信和支付宝发出的支付成功事件，不自动点击、不截图、不联网。

## 第一轮测试

正常使用微信、支付宝或中信银行支付，不必刻意制造大额交易。支付后打开 Money Manager：

- 查看流水是否出现。
- 打开“设置 → 自动记账诊断”，查看结果是“已记账”“已合并”还是“已忽略”。
- 如果金额、收款方或分类错误，请截取支付结果或通知并遮住姓名、卡号和余额。
